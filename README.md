# Student Card

A simple and stylish student profile card created using **HTML5 and CSS3**. The project contains a student image, student information, and a structured card layout.

## 🌐 Technologies Used

* HTML5
* CSS3

## ✨ Features

* Student profile image
* Student information
* External CSS stylesheet
* Card layout
* Colors and font styling
* Margin and padding
* Border and border-radius
* Box-shadow
* Clean and simple design

## 📚 What I Learned

Through this project, I practiced:

* Creating an HTML page structure
* Using an external CSS file
* Adding and displaying images
* Styling elements with CSS
* Using margin and padding
* Creating borders and rounded corners
* Applying box-shadow
* Designing and aligning a card

## 🚀 Future Improvements
